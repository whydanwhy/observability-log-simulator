# Observability Log Simulator

This project simulates a video analytics pipeline and models how system degradation (e.g. memory leaks) impacts business outcomes.

## Features

- Time-based traffic model (quiet, normal, busy)
- Memory leak simulation
- Throughput degradation
- Business-level metrics (detections, customers seated/left)

## Goal

Demonstrate how observability systems can detect:
- Silent failures
- Performance degradation
- Business impact
